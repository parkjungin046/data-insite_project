# 현장답사 체크리스트

담당: A · 목적: 대상지의 복개하천·불투수면·열환경 현황을 직접 눈으로 확인하고, 옛 지도와 대조할 근거 자료 확보

## 사전 준비

- [ ] 대상지 옛 지도(과거 물길이 표시된 지도) 미리 출력/캡처해서 지참
- [ ] 스마트폰 GPS·카메라 준비 (사진에 위치정보 저장되도록 위치서비스 켜기)
- [ ] 답사 시점 계획: 가능하면 비 온 직후(침수·배수 흔적 확인), 한여름 오후(열환경 체감) 각각 1회씩

## 현장 확인 항목

### 1. 물길 · 배수

- [ ] 옛 지도상 물길이 지나가던 자리가 지금은 어떻게 쓰이고 있는지 (도로/주차장/건물 등)
- [ ] 빗물받이·배수구 위치, 막힘/노후 여부
- [ ] 주변보다 낮아 보이는 지점(저지대) - 물이 고인 흔적, 얼룩 확인

### 2. 불투수면

- [ ] 포장면(아스팔트·콘크리트) 비율 육안 확인 구간별 기록
- [ ] 옥상·주차장 등 빗물이 스며들 수 없는 면적 후보지

### 3. 열환경

- [ ] 그늘/녹지 분포, 가로수 유무
- [ ] 체감 온도가 유독 높게 느껴지는 구간 (아스팔트 열기, 바람이 안 통하는 골목 등)

### 4. 주민 인터뷰 (선택, 가능하면)

- [ ] 침수 경험 여부·시기·빈도
- [ ] 여름철 체감 더위, 불편한 점

## 기록 방법

- [ ] 지점마다 번호를 매겨 사진 촬영 (예: P01, P02...)
- [ ] 각 지점에서 무엇을 봤는지 아래 표에 바로 기록
- [ ] 답사 후 이동 경로를 지도에 표시

|---|---|---|---|---|
