# data-insite_project

물순환 중심 토지이용계획 · GIS 분석 · 의사결정 대시보드(웹사이트) 캡스톤디자인 프로젝트

**기술 스택**: Python (GeoPandas, 시뮬레이션) · Streamlit (웹 대시보드)

## 역할 분배

| 역할 | 핵심 산출물 | 담당 업무 | 디자인 담당 |
|---|---|---|---|
| **A** | 물순환 중심 토지이용계획도 | 현장답사, 계획 방향·KPI 설정, 계획도 작성, 발표자료 총괄 | 전체 톤앤매너·색상 컨셉 |
| **B** | 침수·열 저감 성능 분석 | 공공데이터 수집, GIS 중첩분석, 물순환·열환경 시뮬레이션, 성능분석 | 지도·차트 시각화 |
| **C** | 의사결정 대시보드(웹사이트) | 웹 개발(기능 구현), 배포·검증 | UI 레이아웃·컴포넌트 |

## 폴더 구조

```
data/          # 원자료                              — B
analysis/      # GIS 분석·시뮬레이션 스크립트          — B
web/
├─ design/
│  ├─ brand/       # 색상·톤앤매너 가이드              — A
│  ├─ map-viz/      # 지도·차트 스타일, 범례            — B
│  └─ ui/           # 레이아웃·컴포넌트 시안            — C
└─ src/         # 실제 웹사이트 코드                   — C
docs/          # 계획서, 발표자료, 회의록              — A
outputs/       # 최종 계획도, 분석 결과물              — A(통합), B(원본)
```

## 브랜치 전략

`main`(배포/제출본) · `develop`(통합) · `feat/{담당}-{기능}` 형식의 작업 브랜치.
모든 기능 브랜치는 PR을 통해 `develop`으로 병합합니다.
